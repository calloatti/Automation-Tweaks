A collection of quality-of-life tweaks for Timberborn that enhances automation.

More colors.  
Relay and Memory Replicate input colors: When enabled, the building's color is automatically set to match the most recently activated input's color. For Memory, only InputA and InputB are considered (ResetInput is excluded).  
Allows longer names.
